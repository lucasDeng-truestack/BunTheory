The running summary of a booking: a side panel on desktop, a sticky bar on phone, the review card, and the reference block on the done screen.

- Desktop: stays beside the steps, sticky. Phone: collapses into `br-stickybar` at the bottom with the one-line summary, the step count and the next action.
- Unanswered rows read "Not yet" in `cream-faint`. Dates are always written in words.
- Review step: the same rows on one card with an "Edit" link per section, the hold line, and the submit button ("Send request").
- The hold line reads "Your date is held for 3 days while we confirm." The 3 comes from the owner's hold setting.
- No prices, anywhere. Do not add a total row.
- Done: the reference large in the display face (`br-ref`), "We will call you on" plus the customer's own number, a link to the status page, and a plain "Message us" link.
